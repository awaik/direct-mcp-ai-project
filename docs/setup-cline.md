# Подключение LidFly MCP к Cline (Яндекс Директ, Метрика, Вордстат, Вебмастер, VK Реклама, ВКонтакте, Telegram, MAX, Авито)

Эта инструкция покажет, как подключить ИИ-агента **Cline** в VS Code к платформе **[LidFly](https://lidfly.ru/)** через единый MCP-сервер `https://lidfly.ru/mcp/v3`.

После подключения Cline сможет управлять рекламой в **Яндекс Директе**, **VK Рекламе (VK Ads)** и **Авито Рекламе**, анализировать **Яндекс Метрику** и **AppMetrica**, собирать ключевые слова в **Вордстате**, проверять сайт в **Яндекс Вебмастере**, публиковать и планировать посты в **Telegram**, **ВКонтакте** и мессенджере **MAX**, работать с объявлениями и чатами **Авито**, создавать сайты на LidFly и вести задачи в **Пространствах**.

---

## Настройка

В проекте уже подготовлен файл `.cline/mcp_settings.json`:

```json
{
  "mcpServers": {
    "lidfly": {
      "type": "http",
      "url": "https://lidfly.ru/mcp/v3"
    }
  }
}
```

1. Откройте папку этого проекта в VS Code с установленным расширением **Cline** (или перенесите блок `lidfly` в настройки MCP servers внутри Cline).
2. Если ваша версия Cline поддерживает remote MCP OAuth, пройдите вход по email в браузере. Если используется версия со статическими заголовками, подключите ключ по [инструкции для API-ключа](setup-api-key.md) локально и не коммитьте секрет в репозиторий.

---

## Проверка и первые запросы

```text
Покажи мои доступные Пространства, рекламные кабинеты и подключённые площадки (Директ, Метрика, VK, Telegram, MAX, Авито).
```

```text
Проверь мои активные кампании в Яндекс Директе и VK Рекламе за последние 30 дней. Ничего не меняй без отдельного плана.
```

Для любых изменений Cline должен сначала показать вам понятный план и вызвать `call_write_tool` только после вашего согласия (а не read-only `call_tool`).
