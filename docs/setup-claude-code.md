# Подключение LidFly MCP к Claude Code и Claude Desktop (Яндекс Директ, Метрика, Вордстат, Вебмастер, VK Реклама, ВКонтакте, Telegram, MAX, Авито)

Эта инструкция поможет за пару минут подключить **Claude Code** (в терминале или VS Code) и **Claude Desktop** к платформе **[LidFly](https://lidfly.ru/)** через единый MCP-сервер `https://lidfly.ru/mcp/v3`.

После подключения Claude сможет анализировать и вести ваши кампании в **Яндекс Директе**, **VK Рекламе (VK Ads)** и **Авито Рекламе**, проверять цели и конверсии в **Яндекс Метрике** и **AppMetrica**, собирать семантику в **Вордстате**, проводить SEO-аудит в **Яндекс Вебмастере**, выпускать и планировать посты в **Telegram**, **ВКонтакте** и мессенджере **MAX**, работать с объявлениями и чатами **Авито**, создавать сайты на LidFly и писать статьи из больших видео.

> Пошаговая визуальная инструкция с видеороликами и установщиком в один клик также доступна на странице **[lidfly.ru/claude](https://lidfly.ru/claude/)**.

## Вариант 1. Claude Code (терминал или расширение в VS Code)

### Способ А. Работа прямо из этого проекта (рекомендуем)

В корне этого репозитория уже настроены файл подключения `.mcp.json`, правила `CLAUDE.md` и папка `.claude/skills/` со всеми 28 профессиональными навыками LidFly.

1. Скачайте этот репозиторий (или компактный архив только для Claude Code — [`lidfly-claude-code.zip`](https://github.com/awaik/direct-mcp-ai-project/releases/latest/download/lidfly-claude-code.zip)) и откройте папку в VS Code или терминале.
2. Если VS Code спросит о доверии к папке (**Restricted Mode**), нажмите **«Доверять авторам»** — иначе Claude Code не подхватит проектный `.mcp.json`.
3. В панели или терминале Claude Code введите команду `/mcp`, выберите сервер `lidfly` и нажмите **`Authenticate`** (если сервер помечен как `Disabled`, сначала нажмите `Start`).
4. В открывшемся окне браузера введите email вашего кабинета LidFly и 6-значный код из письма. **API-ключ вручную копировать не нужно.**

### Способ Б. Добавление одной командой в любой проект

Вы можете добавить удалённый MCP-сервер LidFly в терминале без API-ключа:

```bash
claude mcp add \
  --transport http \
  lidfly https://lidfly.ru/mcp/v3
```

Или создайте файл `.mcp.json` в корне вашего проекта:

```json
{
  "mcpServers": {
    "lidfly": {
      "type": "http",
      "url": "https://lidfly.ru/mcp/v3"
    }
  }
}
```

После добавления откройте `/mcp`, выберите сервер `lidfly` и нажмите **`Authenticate`**.

## Вариант 2. Claude Desktop (macOS и Windows)

В приложении Claude Desktop подключение работает через встроенные коннекторы (**Connectors**) и режим работы с папкой (**Cowork**):

1. При желании скачайте установщик LidFly на странице **[lidfly.ru/claude](https://lidfly.ru/claude/)** и нажмите **«Установить папку»** — приложение само создаст рабочую папку `~/LidFly` (на macOS) или `%USERPROFILE%\LidFly` (на Windows) с актуальными файлами `CLAUDE.md` и навыками (`skills`).
2. В приложении **Claude Desktop** откройте **Settings (или Customize) → Connectors**.
3. Нажмите **`Add custom connector`** и укажите:

```text
Name: LidFly
URL: https://lidfly.ru/mcp/v3
```

4. Нажмите **`Connect`** и подтвердите вход по email в браузере (OAuth).
5. В новом чате проверьте, что коннектор **LidFly** включён (кнопка `+` → **Connectors**), а для использования локальных скиллов откройте папку проекта в **Cowork** (`Projects → + → Use existing folder`).

> Не используйте `claude_desktop_config.json` для нового OAuth-подключения — этот файл предназначен только для локальных stdio-серверов и устаревших схем.

## Подключение через API-ключ (альтернативный режим)

Если вы предпочитаете статический ключ вместо браузерного OAuth, сначала [задайте переменную окружения `LIDFLY_TOKEN`](setup-api-key.md). В своём `.mcp.json` настройте блок `lidfly` так:

```json
{
  "mcpServers": {
    "lidfly": {
      "type": "http",
      "url": "https://lidfly.ru/mcp/v3",
      "headers": {
        "Authorization": "Bearer ${LIDFLY_TOKEN}"
      }
    }
  }
}
```

Сохраните другие серверы, если они уже есть в файле. Запустите `claude` из терминала с заданной переменной; нажимать `Authenticate` в этом режиме не требуется. Не заменяйте `${LIDFLY_TOKEN}` самим ключом в файле. Подстановка переменных в HTTP headers описана в [документации Claude Code](https://code.claude.com/docs/en/mcp#environment-variable-expansion-in-mcpjson).

Для возврата к OAuth удалите только `headers.Authorization` из подключения `lidfly`, перезапустите Claude Code и выполните `Authenticate` через `/mcp`.

## Проверка и первые запросы в Claude

Отправьте в чат любой из проверочных запросов:

```text
Покажи мои доступные Пространства, рекламные кабинеты и подключённые площадки.
```

```text
Покажи мои активные кампании в Яндекс Директе и проанализируй расход и конверсии за последние 30 дней. Пока ничего не меняй.
```

```text
Подготовь пост для нашего Telegram-канала и канала в мессенджере MAX: сначала отправь предпросмотр в бота и ничего не публикуй без моего подтверждения.
```

Для любого запроса Claude сначала определяет ваш рабочий контекст через `get_provider_context`, находит нужный инструмент через `search_tools` и `get_tool_schema`, после чего выполняет чтение через `call_tool` или предлагает план изменений для `call_write_tool`.

## Безопасность и разрешения (Permissions)

Файл `.claude/settings.json` в этом шаблоне намеренно не отключает проверки безопасности. Read-only запросы выполняются свободно, но любые изменения в рекламе, публикациях или настройках сайтов идут через `call_write_tool` и требуют вашего явного текстового согласия.

Основной source of truth для публичных snippets — `public/js/guides.js` в основном репозитории LidFly.
