# Настройка платформ с нуля: Метрика, цели, Вебмастер, кабинеты

Этот документ — практическое продолжение **Приложения А** книги «Маркетинг в эпоху искусственного интеллекта». Книга объясняет *что и зачем* и намеренно не печатает кнопки (они устаревают); здесь — актуальные *шаги*. Если чего-то из стека у вас ещё нет, соберите по порядку ниже, затем подключайте контур (`README.md` → «Быстрый Старт») и начинайте с read-only.

> Порядок — цепочка зависимостей: **кабинет → счётчик → цели → Вебмастер → Вордстат → подключение к ИИ**. Интерфейсы Яндекса меняются; при расхождении сверяйтесь с официальной справкой (ссылки в конце). Значения счётчиков, целей и порогов вписывайте потом в `PROJECTS.md` — оттуда их берёт ИИ.

---

## 1. Рекламный кабинет (Яндекс Директ)

1. Зайдите на `direct.yandex.ru` под аккаунтом Яндекса (для бизнеса — лучше отдельный, не личный).
2. Создайте рекламодателя (страна, валюта — их потом не сменить, выбирайте вдумчиво).
3. Если ведёте чужую рекламу: доступ к кабинету клиента выдаётся через **представительский доступ** («Доступные аккаунты» в Директ Про) или **агентский логин**. Логин клиента сохраняется в кабинете LidFly вручную (в пакете «Рекламодатель» — один кабинет; для многих клиентов нужен пакет «Агентство»).

**Готово:** вы видите кабинет и его кампании (или пустой кабинет).

---

## 2. Счётчик Яндекс Метрики

1. `metrika.yandex.ru` → **Добавить счётчик** → укажите адрес сайта и имя.
2. Включите нужное (по желанию **Вебвизор** — записи визитов) и создайте счётчик — получите **номер счётчика** и **код счётчика** (тег).
3. Установите код на сайт **на всех страницах**, одним из способов:
   - вставить фрагмент кода в `<head>` каждой страницы (или в общий шаблон/футер);
   - через конструктор сайта — поле «код Метрики»/«счётчик аналитики» в настройках;
   - через Яндекс Тег Менеджер или Google Tag Manager, если он у вас есть.
4. Проверьте установку: в списке счётчиков статус станет «Код найден», а в отчёте **Посещаемость** появятся сегодняшние визиты (зайдите на сайт сами — визит должен отобразиться в течение нескольких минут).

**Частая ловушка:** при переезде/редизайне сайта счётчик слетает. После любых работ с сайтом — проверьте, что статус «Код найден» и визиты идут.

**В `PROJECTS.md`:** впишите номер счётчика (`counter_id`).

---

## 3. Цели в Метрике

Настройки счётчика → вкладка **Цели** → **Добавить цель**. Минимум — по одной на каждый ваш «результат»:

- **Заявка с формы.** Тип «JavaScript-событие» (надёжнее всего — попросите разработчика/конструктор отправлять `ym(counter_id,'reachGoal','lead')` после успешной отправки) или «Отправка формы» / «Страница спасибо» (цель на URL `/thanks`), если отдельная страница благодарности есть.
- **Звонок.** Тип «Клик по номеру телефона» — цель на клик по ссылке `tel:` (на мобильных это реальные звонки). Если звонков много и важен источник — подключайте коллтрекинг (подменные номера); это отдельный платный слой.
- (Опц.) **Заказ/оплата** для интернет-магазина.

**Проверка:** оставьте тестовую заявку/кликните по телефону → в отчёте **Конверсии** цель должна отметиться. Ноль срабатываний за неделю живого трафика = цель сломана.

**В `PROJECTS.md`:** впишите ID и названия целей; отметьте, какая цель — **ключевая** (реальная продажа/заявка), чтобы ИИ оптимизировал на неё, а не на микро-действия.

> Почему это критично: автостратегии Директа учатся на целях. Если кампания оптимизируется на дешёвую микро-цель (скачал файл, прошёл тест), а не на заявку/продажу — она «обучается» на пустых действиях, а реальные продажи остаются невидимыми. Явно указывайте ключевую цель.

## 4. Яндекс Вебмастер

1. `webmaster.yandex.ru` → **Добавить сайт** → введите адрес.
2. **Подтвердите права** одним из способов (выберите удобный):
   - **Мета-тег** — вставить выданный `<meta name="yandex-verification" ...>` в `<head>` главной страницы;
   - **HTML-файл** — загрузить выданный файл в корень сайта;
   - **DNS-запись** — добавить TXT-запись у регистратора домена;
   - **Через Метрику** — если счётчик уже стоит и привязан к тому же аккаунту, права подтверждаются автоматически (самый простой путь, если шаг 2 сделан).
3. После подтверждения добавьте **карту сайта (sitemap.xml)** в разделе «Индексирование → Файлы Sitemap».

**Готово:** сайт подтверждён; через несколько дней появятся данные по индексации и поисковым запросам. Новые страницы отправляйте на **переобход** («Индексирование → Переобход страниц»), чтобы поиск узнал о них за дни, а не недели.

**В `PROJECTS.md`:** отметьте, что Вебмастер подключён (LidFly использует отдельный OAuth Вебмастера; `host_id` берётся через `webmaster_get_hosts`).

---

## 5. Яндекс Вордстат

- `wordstat.yandex.ru` — доступен под любым аккаунтом Яндекса, отдельной установки не требует.
- В контуре LidFly работает через Yandex Search API независимо от подключения Директа — то есть спрос можно проверять, даже если рекламу ещё не запускали.

**Готово:** вы (или ИИ) получаете частотность запроса и динамику спроса.

---

## 6. Подключение к ИИ-контуру (LidFly)

1. Зарегистрируйтесь: `lidfly.ru/app`.
2. Подключите провайдеров в кабинете (OAuth): Яндекс Директ/Метрика, Яндекс Вебмастер (отдельный OAuth), VK Ads, Авито Реклама, сайты LidFly.
3. Подключите ИИ-клиент к endpoint `https://lidfly.ru/mcp/v3` — по инструкции своего клиента (`docs/setup-*.md`: Claude Code, ChatGPT, Cursor, Codex и др.).
4. Заполните `PROJECTS.md` (бизнес, KPI, счётчики, цели, сезонность) и `LEGAL.md` (запрещённые формулировки).
5. Проверьте scope и начните с чтения:

   ```text
   Покажи мои доступные Пространства и рекламные кабинеты.
   Проверь структуру кампаний и расход за неделю. Ничего не меняй.
   ```

**Правило первой недели (из главы 4 книги):** только чтение. Права на запись — потом, по одному кабинету, когда появилось доверие. Действия записи всегда идут через план → подтверждение → перечитку.
