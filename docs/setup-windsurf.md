# Подключение LidFly MCP к Windsurf (Яндекс Директ, Метрика, Вордстат, Вебмастер, VK Реклама, ВКонтакте, Telegram, MAX, Авито)

Эта инструкция покажет, как подключить ИИ-редактор **Windsurf (Cascade)** к платформе **[LidFly](https://lidfly.ru/)** через единый MCP-сервер `https://lidfly.ru/mcp/v3`.

После подключения Cascade сможет работать с вашими кампаниями в **Яндекс Директе**, **VK Рекламе (VK Ads)** и **Авито Рекламе**, проверять цели и конверсии в **Яндекс Метрике** и **AppMetrica**, собирать семантику в **Вордстате**, проводить SEO-аудит в **Яндекс Вебмастере**, выпускать и планировать посты в **Telegram**, **ВКонтакте** и мессенджере **MAX**, управлять объявлениями и отвечать покупателям на **Авито**, а также вести сайты и проекты в **Пространствах LidFly**.

---

## Настройка

Windsurf читает глобальный конфигурационный файл `~/.codeium/windsurf/mcp_config.json` (также в корне этого шаблона подготовлен образец `.windsurf/mcp.json`):

```json
{
  "mcpServers": {
    "lidfly": {
      "serverUrl": "https://lidfly.ru/mcp/v3"
    }
  }
}
```

1. Добавьте блок `lidfly` в `~/.codeium/windsurf/mcp_config.json` и откройте папку этого проекта в **Windsurf**, чтобы Cascade подхватил правила из `AGENTS.md` и навыки (`skills`).
2. Перезапустите Windsurf и пройдите OAuth-вход по email вашего кабинета [lidfly.ru/app](https://lidfly.ru/app), когда Cascade покажет кнопку подключения. **API-ключ вручную копировать не нужно.**

---

## Проверка и первые запросы в Cascade

```text
Покажи мои доступные Пространства, рекламные кабинеты и подключённые площадки (Директ, Метрика, VK, Telegram, MAX, Авито).
```

```text
Проверь активные кампании в Яндекс Директе за последние 30 дней: расход, клики, конверсии по Метрике. Ничего не меняй без отдельного плана.
```

```text
Подготовь пост для нашего Telegram-канала и канала в мессенджере MAX: сначала отправь предпросмотр в бота и жди моего подтверждения.
```

Для любых задач Cascade сначала определяет нужный кабинет или проект через `get_provider_context` / `resolve_campaign_scope`, а любые изменения выполняет через `call_write_tool` только после вашего подтверждения.
