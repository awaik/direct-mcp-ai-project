# Подключение LidFly MCP к ChatGPT

LidFly подключается к ChatGPT как собственное MCP-приложение в режиме разработчика. Нужна подписка ChatGPT Plus, Pro, Business, Enterprise или Edu и веб-версия chatgpt.com: режим разработчика включается только в браузере.

## Настройка

1. Откройте chatgpt.com -> Настройки -> Безопасность и вход и включите «Режим разработчика» (Developer mode).
2. Перейдите в «Плагины» (chatgpt.com/plugins), нажмите «Добавить» -> «Создать MCP-приложение».
3. Название — `LidFly`, аутентификация — `OAuth`, URL сервера:

```text
https://lidfly.ru/mcp/v3
```

4. Отметьте «Я понимаю и хочу продолжить» и нажмите «Создать».
5. Нажмите «Перейти к LidFly», введите email кабинета LidFly и код из письма.

OAuth-токены MCP отличаются от API-ключа личного кабинета. API-ключ вручную копировать не нужно.

## Проверка

```text
Покажи мои доступные Пространства и рекламные кабинеты.
```

## Обновление списка инструментов

ChatGPT хранит снимок списка инструментов и сам его не перечитывает. Если ChatGPT не видит `get_provider_context` / `resolve_campaign_scope`, других новых инструментов LidFly или пишет об ошибке параметров, откройте Настройки -> Плагины -> LidFly и нажмите «Обновить инструменты» (Refresh), затем начните новый чат.

Если приложение создано со старым адресом `https://lidfly.ru/mcp/lite`, адрес в нём поменять нельзя: создайте новое приложение с `https://lidfly.ru/mcp/v3`, проверьте вход и удалите старое.

## Как Работать

Для действий с кампаниями просите сначала read-only аудит:

```text
Проверь кампанию "Бренд Москва", найди scope сам, ничего не меняй без отдельного плана.
```

Write-действия должны идти через `call_write_tool` после плана и вашего явного текстового подтверждения.
