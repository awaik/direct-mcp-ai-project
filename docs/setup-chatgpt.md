# Подключение LidFly MCP к ChatGPT

ChatGPT подключается через MCP server в Connected apps. Нужна подписка ChatGPT Plus, Pro или Team.

## Настройка

1. Откройте ChatGPT -> Settings -> Connected apps.
2. Нажмите `Add` и выберите `MCP server`.
3. Вставьте URL:

```text
https://lidfly.ru/mcp/v3
```

4. ChatGPT откроет браузерную авторизацию LidFly.
5. Введите email и код из письма.

OAuth-токены MCP отличаются от API-ключа личного кабинета. API-ключ вручную копировать не нужно.

## Проверка

```text
Покажи мои доступные Пространства и рекламные кабинеты.
```

Если ChatGPT видит старый набор инструментов или не видит `get_provider_context` / `resolve_campaign_scope`, удалите подключение и добавьте его заново: клиенты иногда кешируют manifest.

## Как Работать

Для действий с кампаниями просите сначала read-only аудит:

```text
Проверь кампанию "Бренд Москва", найди scope сам, ничего не меняй без отдельного плана.
```

Write-действия должны идти через `call_write_tool` после плана и вашего явного текстового подтверждения.
