# Подключение LidFly MCP к VS Code и GitHub Copilot (Яндекс Директ, Метрика, Вордстат, Вебмастер, VK Реклама, ВКонтакте, Telegram, MAX, Авито)

Эта инструкция покажет, как подключить **VS Code** (GitHub Copilot Chat в режиме Agent, Continue.dev и другие MCP-расширения) к платформе **[LidFly](https://lidfly.ru/)** через единый MCP-сервер `https://lidfly.ru/mcp/v3`.

После подключения вы сможете прямо из VS Code управлять рекламой в **Яндекс Директе**, **VK Рекламе (VK Ads)** и **Авито Рекламе**, проверять отчёты **Яндекс Метрики** и **AppMetrica**, исследовать спрос в **Вордстате**, проверять индексацию сайта в **Яндекс Вебмастере**, выпускать и планировать посты в **Telegram**, **ВКонтакте** и мессенджере **MAX**, работать с объявлениями и чатами **Авито**, а также вести сайты и проекты в **Пространствах LidFly**.

> **Важно: VS Code — это оболочка.** Если внутри VS Code вы используете расширение **Claude Code** или **OpenAI Codex**, настраивать отдельный `.vscode/mcp.json` не нужно — используйте инструкцию [Claude Code](setup-claude-code.md) или [OpenAI Codex](setup-codex.md). Файл `.vscode/mcp.json` ниже нужен для встроенного MCP в **GitHub Copilot Chat** и расширений, которые читают стандартный конфиг VS Code.

## Быстрая настройка (OAuth — рекомендуемый способ)

В корне этого репозитория уже лежит готовый файл `.vscode/mcp.json`, а также правила `AGENTS.md` и папка `.agents/skills/`:

```json
{
  "servers": {
    "lidfly": {
      "type": "http",
      "url": "https://lidfly.ru/mcp/v3"
    }
  }
}
```

1. Откройте папку проекта в **VS Code** (`File → Open Folder`) и подтвердите доверие к папке, если откроется окно **Restricted Mode**.
2. При первом обращении к серверу `lidfly` нажмите кнопку **`Authenticate` / `Connect` / `Login`** и войдите в браузере по email вашего кабинета [lidfly.ru/app](https://lidfly.ru/app). **API-ключ вручную копировать не нужно.**
   *(Если сервер показывает `Failed` и доступна кнопка `Authenticate` или `Login`, сначала нажмите её и завершите вход в браузере.)*

## Проверка и первые запросы

Откройте **Copilot Chat** (режим **Agent**) и напишите:

```text
Покажи мои доступные Пространства, рекламные кабинеты и подключённые площадки (Директ, Метрика, VK, Telegram, MAX, Авито).
```

```text
Проверь мои активные кампании в Яндекс Директе за последние 30 дней, сравни расход с конверсиями в Метрике и ничего не меняй без отдельного плана.
```

Ожидаемый порядок работы агента: `get_provider_context` для определения нужного проекта и кабинета, затем `search_tools` → `get_tool_schema` → `call_tool` (для чтения) или `call_write_tool` (после вашего подтверждения плана).

## Подключение через API-ключ

Для встроенного MCP в VS Code / GitHub Copilot сначала [задайте переменную окружения `LIDFLY_TOKEN`](setup-api-key.md), затем настройте свой `.vscode/mcp.json`:

```json
{
  "servers": {
    "lidfly": {
      "type": "http",
      "url": "https://lidfly.ru/mcp/v3",
      "headers": {
        "Authorization": "Bearer ${env:LIDFLY_TOKEN}"
      }
    }
  }
}
```

Сохраните остальные серверы в файле. Полностью закройте VS Code и запустите `code .` из терминала с заданной переменной `LIDFLY_TOKEN` (уже открытый VS Code может использовать старое окружение).

Запустите сервер через команду палитры `MCP: List Servers` и выполните запрос из раздела «Проверка». Для возврата к OAuth удалите только блок `headers.Authorization` из подключения `lidfly`, перезапустите сервер и пройдите авторизацию в браузере.

Справка: [конфигурация MCP в VS Code](https://code.visualstudio.com/docs/agents/reference/mcp-configuration).

## Legacy Fallback

Если конкретное старое расширение поддерживает только локальный `stdio` MCP, используйте `mcp-remote` локально с Bearer-заголовком. Не коммитьте API-ключ в Git и не меняйте основной `.vscode/mcp.json` без необходимости.
