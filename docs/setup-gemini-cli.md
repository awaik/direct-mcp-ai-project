# Подключение LidFly MCP к Gemini CLI (Яндекс Директ, Метрика, Вордстат, Вебмастер, VK Реклама, ВКонтакте, Telegram, MAX, Авито)

Эта инструкция покажет, как подключить **Gemini CLI** к платформе **[LidFly](https://lidfly.ru/)** через единый MCP-сервер `https://lidfly.ru/mcp/v3`.

После подключения Gemini CLI сможет управлять рекламой в **Яндекс Директе**, **VK Рекламе (VK Ads)** и **Авито Рекламе**, проверять отчёты **Яндекс Метрики** и **AppMetrica**, собирать семантику в **Вордстате**, проводить SEO-аудит в **Яндекс Вебмастере**, выпускать и планировать посты в **Telegram**, **ВКонтакте** и мессенджере **MAX**, работать с объявлениями и покупателями на **Авито**, создавать сайты на LidFly и писать статьи из больших видео.

---

## Настройка

Gemini CLI читает проектный файл `.gemini/settings.json` (уже включён в этот репозиторий) или глобальный `~/.gemini/settings.json`:

```json
{
  "mcpServers": {
    "lidfly": {
      "url": "https://lidfly.ru/mcp/v3"
    }
  }
}
```

1. Откройте папку этого проекта в терминале — Gemini CLI автоматически прочитает `.gemini/settings.json`, корневые правила `AGENTS.md` / `CLAUDE.md` и навыки (`skills`).
2. При первом запуске пройдите OAuth-вход по email вашего кабинета [lidfly.ru/app](https://lidfly.ru/app), когда Gemini CLI запросит авторизацию. Заголовок с API-ключом используйте только как резервный вариант.

---

## Проверка и первые запросы

Запустите сессию в папке проекта:

```bash
gemini
```

И отправьте в чат проверочный запрос:

```text
Покажи мои доступные Пространства, рекламные кабинеты и подключённые площадки (Директ, Метрика, VK, Telegram, MAX, Авито).
```

```text
Проверь мои активные кампании в Яндекс Директе и конверсии по Метрике за последние 30 дней. Ничего не меняй без отдельного плана.
```

Gemini читает корневые `AGENTS.md` и `CLAUDE.md`; отдельный входной файл правил для Gemini в этом шаблоне не требуется.
