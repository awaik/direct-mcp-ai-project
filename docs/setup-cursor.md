# Подключение LidFly MCP к Cursor (Яндекс Директ, Метрика, Вордстат, Вебмастер, VK Реклама, ВКонтакте, Telegram, MAX, Авито)

Эта инструкция покажет, как за пару минут подключить редактор **Cursor** к платформе **[LidFly](https://lidfly.ru/)** через единый MCP-сервер `https://lidfly.ru/mcp/v3`.

После подключения ИИ-агент в Cursor сможет управлять рекламой в **Яндекс Директе**, **VK Рекламе (VK Ads)** и **Авито Рекламе**, проверять цели и конверсии в **Яндекс Метрике** и **AppMetrica**, собирать семантику в **Вордстате**, проводить SEO-аудит в **Яндекс Вебмастере**, публиковать и планировать посты в **Telegram**, **ВКонтакте** и мессенджере **MAX**, работать с объявлениями и покупателями на **Авито**, создавать сайты на LidFly и писать статьи из больших видео.

---

## Быстрая настройка

### Вариант 1. Открыть готовый проект (рекомендуем)

В этом репозитории уже настроены конфиг `.cursor/mcp.json`, правила `AGENTS.md` и папка `.agents/skills/` со всеми 27 профессиональными навыками LidFly.

1. Скачайте этот репозиторий (или компактный архив специально для Cursor — [`lidfly-cursor.zip`](https://github.com/awaik/direct-mcp-ai-project/releases/latest/download/lidfly-cursor.zip)) и откройте папку в **Cursor** (`File → Open Folder`).
2. Перезапустите Cursor и нажмите **`Authenticate` / `Connect` / `Login`** рядом с сервером `lidfly`, когда клиент предложит войти.
3. Подтвердите вход в браузере по email вашего кабинета [lidfly.ru/app](https://lidfly.ru/app). **Копировать API-ключ вручную не нужно.**

### Вариант 2. Добавить в существующий проект или глобально

Проверьте или создайте файл `.cursor/mcp.json` в корне вашего проекта:

```json
{
  "mcpServers": {
    "lidfly": {
      "url": "https://lidfly.ru/mcp/v3"
    }
  }
}
```

Если Cursor не подхватил проектный файл автоматически, добавьте сервер в настройках **Cursor Settings → MCP → Add new MCP server**:

```text
Name: lidfly
Type: http (или streamableHttp)
URL: https://lidfly.ru/mcp/v3
```

> Если сервер в списке помечен как `Failed` и рядом отображается кнопка **`Authenticate`** или **`Login`**, сначала нажмите её и завершите вход в браузере.

## Проверка и первые запросы в Cursor

Откройте панель чата Cursor (режим **Agent**) и отправьте любой из запросов:

```text
Покажи мои доступные Пространства, рекламные кабинеты и подключённые площадки (Директ, Метрика, VK, Telegram, MAX, Авито).
```

```text
Проанализируй мои активные кампании в Яндекс Директе и конверсии по целям Метрики за последние 30 дней. Ничего не меняй без отдельного плана.
```

```text
Подготовь пост для нашего Telegram-канала и канала в мессенджере MAX: сначала отправь предпросмотр в бота и жди моего подтверждения.
```

Для любых изменений (ставки, бюджеты, запуск кампаний, выпуск постов, обновление цен на Авито или правок на сайте) Cursor сначала показывает план и выполняет запись через `call_write_tool` только после вашего текстового подтверждения.
