# Реклама в MAX: выбор площадки и границы API

Проверено 20.10.2026: живой каталог VK Ads, поля и шаблоны; отдельно — разрешённые
остановленные пробы создания. Каталоговый допуск и фактическое принятие POST различаются.

1. Уточни размещение: реклама **внутри MAX** или продвижение канала MAX **в ленте ВК**.
   В v3 найди `search_tools("реклама в MAX")`, прочитай схему, выбери кабинет через
   `get_provider_context(provider="vk")`. Вызови `vk_get_packages(placement="max")`.
   Этот фильтр означает только подтверждённые MAX-only площадки; `max_channel` сам
   по себе не доказывает размещение. Неполный каталог нельзя считать полным списком.
2. Выбирай доступный кабинету пакет с `write_contract=verified_stopped`: проверены
   4844 (сайт/клики), 4843 (канал/клики), 4841 (канал/подписки). Эти ID не заменяют
   свежую проверку `package_request=allowed`, площадки, URL policy и `goal_mode`.
   В этих пакетах `goal_mode=forbidden`: не отправляй `priced_goal` из внутренних
   запросов интерфейса VK. Каталоговый default не является текущей стратегией.
3. Настройки кампании задавай через `messenger_max`:
   `{"strategy":{"type":"average_clicks","value":"10.25"},"budget":{"type":"period","value":"1000"}}`.
   Для period нужен `date_end`. Weekly — бюджет на календарную неделю, только для
   кликов; справка VK допускает перенос остатка до 30% недельного бюджета. Это
   правило платформы, а не отдельный параметр суммы или дневной лимит.
   `max_clicks`/`max_conversions` требуют `value:null`; `average_clicks`/
   `average_conversions` — среднюю цену; `max_profit` — маржу в рублях.
   У группы только `auto_targetings` и `income_grade` (null снимает фильтр).
   Бюджет и стратегия наследуются от кампании. Не используй для MAX обычные
   `budget_limit`, `budget_limit_day`, `price`, `max_price`, `autobidding_mode`:
   VK может показывать их автоматически, не отражая текущие MAX-настройки.
   Для гео читай `vk_get_regions(flags="geo_tree_max")`; выбери `pads:[3464710]`.
   Создание: `vk_prepare_campaign` → подтверждение → `vk_create_campaign`.
   Обновление: `vk_prepare_campaign_update` → подтверждение → `vk_update_campaign`.
   Группы: `vk_prepare_ad_group`/`vk_prepare_ad_group_update` → соответствующий writer.
   Сохраняй normalized_arguments вместе с max_preconditions и scope. Если исходные
   настройки изменились, подготовь новое подтверждение. Частичный patch кампании
   сохраняет остальные компоненты messenger_max; сырой POST VK заменяет весь блок.
   Создаются только остановленные объекты без объявлений. Старые пакеты 4822/4796/4828
   отклонены VK в проверенном кабинете: не повторяй тот же payload и не перебирай
   другие пакеты без свежего preflight и согласования изменённого результата.
4. Для уже существующей группы проверь выбранные pads через `vk_get_pads_tree`.
   Подготовь объявление по patterns текущего пакета. Запрос
   `vk_get_banner_fields(roles=["title_72","text_108","cta_max","image_1280x720","icon_256x256"])`
   возвращает ограничения и enum целиком; учитывай missing roles/неполноту.
   Шаблоны 646/647 — альтернативы. Тексты/CTA проверяются общим preflight.
   Геометрию бери из каталога; не обещай пригодность экспортов с апскейлом или
   обрезкой больше 30%. `max.ru` разрешается через GET; при ошибке не регистрируй
   его через POST как обычный сайт.
5. Изменение объявления: `vk_prepare_banner_update` → показать итог → подтверждение
   → `vk_update_banner`. Переданная секция `content`/`textblocks`/`urls` заменяется
   целиком. При неизвестном исходе используй `get_write_operation_status`;
   повторный POST не является способом проверки.
6. Показывай отдельно создание, модерацию, статус и наблюдаемый `ord_marker`.
   Отсутствие маркера не доказывает ошибку реквизитов; остановленный объект не
   подтверждает момент появления ERID или статистику подписок. Запуск — отдельное
   подтверждённое действие. Пустая шкала прогноза не означает нулевую аудиторию.

Порог 1 000 подписчиков относится к каналам-площадкам MAX. Рекламируемый канал
должен быть публичным; не переноси на него порог площадки. Внутри MAX мобильное
размещение; по справке бонусы на эту рекламу не распространяются. Маркировку
выполняет VK, но агентские реквизиты и отчётность требуют отдельной проверки.

Источники: [реклама внутри MAX](https://ads.vk.ru/help/general/network/promotion_in_max),
[продвижение каналов](https://ads.vk.ru/help/general/network/promo_channel),
[маркировка](https://ads.vk.ru/help/ord/labeling),
[Banner API](https://ads.vk.ru/doc/api/object/Banner). Описания справки — датированные
факты исходного исследования; live-проверка подтверждает каталоги, остановленные create/update/read-back и наследование.
Платные показы, статистика подписок и момент появления ERID этим не проверялись.
