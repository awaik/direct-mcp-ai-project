# Лид-форма и несколько изображений в одном объявлении

Форма привязывается при создании кампании через `lead_form_id`. Объявлению ссылка
не нужна: VK подставит `leadads://<id>/`. Проверено остановленным созданием и
обратным чтением 26.10.2026. Источники:
[Быстрый старт](https://ads.vk.com/doc/api/info/Быстрый%20старт),
[LeadForms](https://ads.vk.com/doc/api/resource/LeadForms),
[Banner](https://ads.vk.com/doc/api/resource/Banner).

1. Разреши точный кабинет и проект. Вызови `vk_get_lead_forms`, покажи названия
   и согласуй форму. Если её нет, пользователь создаёт форму в интерфейсе VK.
2. Прочитай `vk_get_packages(objective="leadads", available_only=true)`.
   Для event 51 не передавай `priced_goal`: ID формы не является source_id.
3. `vk_prepare_campaign(lead_form_id=...)` с одной стартовой группой. Покажи форму,
   пакет, аудиторию, бюджет и остановленный статус, получи подтверждение.
   Создай кампанию через `vk_create_campaign` с теми же аргументами; проверь
   `lead_form_binding.status=verified`. При unverified/mismatch — статус операции,
   без нового POST. Остальные группы проверяются отдельно.
4. Загрузи каждое изображение через `vk_upload_image(role=...)`:
   логотип → `icon_256x256`; 1:1 → `image_600x600`; 16:9 → `image_1080x607`;
   9:16 → `image_607x1080`; 4:5 → `image_1080x1350`.
   Если пропорция отличается, согласуй обрезку и только затем `allow_crop:true`.
   Покажи ссылку на сохранённый VK вариант. Генерация 9:16 использует
   `vk_story_1080x1920`; оплаченная генерация требует отдельного согласия.
5. Собери **один** Banner со всеми ролями и текстами, без `urls`.
   `vk_prepare_banner` должен вернуть `ready=true`: каждый переданный слот
   покрывается полным шаблоном. Покажи `format_coverage`, согласуй и создай через
   `vk_create_banner`. Проверь один ID объявления, все изображения и
   `lead_form_binding.status=verified`. Не разбивай форматы на разные объявления.
6. Для добавления/замены роли используй `vk_prepare_banner_update` и
   `vk_update_banner(content_changes={"image_607x1080":{"id":123}})`;
   `null` удаляет роль. Остальные изображения сохраняются. Поле `content`
   по-прежнему заменяет всю секцию, совместно с `content_changes` запрещено.
7. Покажи реальные ID, форму, форматы, остановленный статус и **отдельно**
   статус модерации. Запуск — отдельное подтверждённое действие.

1:1 и 16:9 — базовый набор; 4:5 дополняет ленты. В пакете 3215 формат 9:16
работает только в VK Stories. Проверяй текущие площадки по `format_coverage`:
при отключённых Stories 9:16 не допускается. Никогда не заменяй его на 4:5 без
согласия: это разные роли. HTTP-строка `vk.com/leadads/form/...` не создаёт
привязку — наблюдался отказ модерации `BAD_URLTYPE`.

Создание самих форм и сплит-тест `lead_form_group` не поддержаны. Модерация и
показы не гарантируются успешным созданием. Изменение объекта уже существующей
кампании VK отклоняет как `create_only_field` для `ad_object_type/ad_object_id`
(проверка 26.10.2026): создавай новую кампанию с `lead_form_id`. Новая группа
наследует форму кампании; связь проверяется через `_ad_group_ids__in`. Явный
служебный URL той же формы допустим, но для нового объявления он не нужен.
