# LidFly
Known URL/id/domain/name: get_provider_context(provider: "lidfly", query: "...") returns latest publication revision; if unknown, fall back to lidfly_list_sites. Require idle; serialize writes; never blind-retry.

1. Map nested page paths with lidfly_list_pages; read lidfly_get_page_snapshot and follow next_safe_call for ownership. Legacy: lidfly_get_page(subdomain, slug), lidfly_get_block(subdomain, slug, index).
2. Separate references from import-and-place. Define navigation/zoom/CTA/form; read section snapshots or lidfly_recommend_page_blueprint. Filter lidfly_list_blocks, inspect description/purpose/visible_when and lidfly_get_block_definition. Paginate offset + matches.length while has_more. Disclose unsupported interactions; never substitute a button for card navigation. Details: references/managed-pages.md.
3. Discover lidfly_list_site_design_templates. Reusable chrome is not singleton: use registry-level reusable blocks. Check theme/CSS/fonts/forms. Preview assets/pages/config in lidfly_preview_site_changeset with acceptance routes/references; confirm one digest, apply unchanged. Legacy: lidfly_update_block(subdomain, slug, index, props).
4. Reread snapshots; verify absent routes and asset SHA/path/placement. Exact-revision desktop/mobile QA: image/title clicks, anchors, zoom, Tab/Enter, link names. Screenshots cannot prove interaction. Require postconditions/QA; disclose warnings.

Taxonomy: sequential; follow next_safe_call while pagination.has_more. On conflict reread include_archived=true; restore the archived node only. emit_sitemap_while_blocked is per-publish and keeps noindex/robots unchanged. Static root: upload→preview→lidfly_deploy_static_site(preview_id,digest,revision,confirm_replace); collisions fail closed. Assets immutable; forms POST /api/leads. Do not promise arbitrary backend/Python/Node upload; use lidfly_list_managed_endpoints for calculators and AI forms.
