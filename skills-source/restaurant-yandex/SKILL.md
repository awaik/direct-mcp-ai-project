# Ресторан и Яндекс Бизнес

Используй этот skill для единого меню на managed-сайте LidFly, постоянного фида Яндекс Бизнеса, карточки в Картах и аналитики действий посетителей.

## Меню

Единый источник меню — все блоки `restaurant-menu` сайта. Редактируй их через `lidfly_get_page` → `lidfly_get_block` → `lidfly_update_block`. Сохраняй стабильные `category`/`item id`; недоступное блюдо помечай `availability=unavailable`, не удаляя его.

Перед включением фида всегда вызывай `lidfly_validate_yandex_business_menu`. Начни ответ с количества блюд, которые войдут и будут исключены, затем покажи точные `page_slug`/`block_index`/`item_id`. Ошибки глобального контракта блокируют публикацию; ошибка отдельного блюда исключает только его; warnings не блокируют публикацию.

Покажи пользователю, что постоянный URL YML будет публичным. Только после следующего текстового подтверждения вызови `lidfly_set_yandex_business_menu_feed` с `enabled=true` и свежим `expected_publication_revision`. После публикации дай `feed_url`, `xlsx_url` и путь в кабинете Яндекс Бизнеса. При `indexing_blocked` объясни, что настройка сохранена, но публичные файлы ожидаемо удалены до открытия индексации.

`lidfly_export_restaurant_menu` оставлен для разовой CSV/YML-выгрузки; для постоянной синхронизации используй validate → подтверждение → set. Managed WebP для фотографии может быть преобразован в JPEG; неподходящее или непроверенное внешнее изображение пропускается с предупреждением.

## Карты и аналитика

Для аналитики Карт используй `metrika_get_yandex_business_events`. При `selection_required` покажи кандидатов и запроси точный `counter_id` или `organization_id`. Не угадывай по названию. Отношения просмотров и действий называй отношениями агрегатов, а не пользовательской воронкой; предполагаемое посещение вероятностное и может учитываться в течение 21 дня. Не обещай отказы, глубину и время на сайте для автоматического счётчика.

JSON-LD Restaurant/Menu сайт формирует автоматически. Поля кухни, брони, цен, адреса и часов меняй через `lidfly_get_site_seo_profile` → `lidfly_update_site_seo_profile` с CAS. `orgId` организации получай через `get_businesses` и используй для `yandex-maps-embed`.

Отзывы, посты и акции владелец публикует в кабинете вручную: готовь тексты, но не утверждай, что опубликовал их через API.

Платную генерацию изображения запускай только после показа prompt, format/crop и отдельного текстового подтверждения пользователя.
