# Улучшить кампанию по ID или названию

Используй skills `mcp-v3-provider-context`, `workspace-project-manager` и профильный skill провайдера.

Кампания:

```text
$ARGUMENTS
```

Порядок:

1. Определи провайдера. Если он не указан, сначала найди scope через `get_provider_context`.
2. Для названия или ID кампании вызови `resolve_campaign_scope` с подходящим `provider` и `query`.
3. Перенеси returned `scope_arguments`/`next_call.arguments` в read-only calls.
4. Получи настройки, структуру, объявления/группы/ключи и статистику за согласованный период.
5. Проверь бюджет, цель, стратегию, конверсии, CPA, поисковые запросы/аудитории, креативы и каннибализацию.
6. Покажи диагностику и план улучшений по приоритетам.
7. Не вноси изменения без явного подтверждения. После write обязательно перечитай состояние.
8. Если выводы надо сохранить, сначала resolve `workspace_project_id`, затем запиши решение или документ в Пространство.
