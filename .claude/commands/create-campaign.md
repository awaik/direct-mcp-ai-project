# Создать кампанию Яндекс Директа из файла

Используй skill `yandex-direct-campaign-builder`.

Файл конфигурации:

```text
$ARGUMENTS
```

Обязательный порядок:

1. Прочитай файл и выдели продукт, посадочную, гео, бюджет, цели, семантику и ограничения.
2. Если кабинет или Пространство не очевидны, вызови `get_provider_context({ provider: "yandex" })`.
3. Если в файле названа существующая кампания, сначала вызови `resolve_campaign_scope({ provider: "yandex", query })`.
4. Найди нужные инструменты через `search_tools`, прочитай схемы через `get_tool_schema`.
5. Проведи read-only проверки: существующие кампании, Метрика/цели, Wordstat, каннибализация.
6. Покажи план создания и риски. Без явного текстового подтверждения не вызывай write-инструменты.
7. После подтверждения используй современный путь `add_unified_campaign` -> `add_adgroup`/`add_adgroups` -> `add_responsive_ad`; legacy TEXT_AD путь только если пользователь прямо просит compatibility.
8. Для campaign write в агентских/командных Пространствах передавай точный `workspace_project_id`.
