# Создать кампанию Яндекс Директа из описания

Используй skill `yandex-direct-campaign-builder`.

Описание пользователя:

```text
$ARGUMENTS
```

Обязательный порядок:

1. Преврати описание в краткий бриф: продукт, оффер, посадочная, гео, бюджет, KPI, целевое действие, ограничения.
2. Если не хватает безопасных данных для плана, задай точные вопросы.
3. Определи provider/project scope через `get_provider_context`; если есть кампания по имени, используй `resolve_campaign_scope`.
4. Найди и проверь схемы нужных инструментов через `search_tools` и `get_tool_schema`.
5. Проведи read-only проверки до записи.
6. Покажи структуру кампании, бюджет, группы, семантику, минус-темы, объявления и риски.
7. Жди явного подтверждения перед `call_write_tool`.
8. Используй modern EPK/responsive workflow; legacy text tools не ставь дефолтом.
